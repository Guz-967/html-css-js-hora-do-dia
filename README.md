# Hora do Dia

Projeto desenvolvido em HTML, CSSS e JavaScript com o objetivo de praticar lógica de programação, operador Date, condicionais e manipulação do DOM por meio de um site que altera sua interface de acordo com o horário atual.

## Sobre o Projeto

O projeto exibe a hora atual e muda sua interface de acordo para cada período do dia (manhã, tarde e noite), alterando suas cores e imagem central para se adequar com os 3 períodos do dia.

### Funcionalidades:

- Interface dinâmica;
- Adequação ao horário atual;
